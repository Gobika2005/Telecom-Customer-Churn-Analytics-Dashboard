# Telecom Customer Churn Analytics Dashboard

## Project Overview

This project analyzes telecom customer churn using an interactive Power BI dashboard. The dashboard provides business insights into customer retention, churn trends, contract preferences, internet service usage, and payment behavior. It enables stakeholders to make data-driven decisions through interactive visualizations and KPI monitoring.

## Problem Statement

Customer retention is a significant challenge in the telecom industry. The objective of this project is to analyze customer churn patterns, identify high-risk customer segments, and provide actionable insights that support customer retention strategies.

## Dataset Information

**Dataset:** Telco Customer Churn Dataset

- Total Customers: 7,043
- Total Features: 21
- Target Variable: Churn (Yes/No)

## Key Business Insights

- Overall churn rate is **26.54%**
- Month-to-month customers show the highest churn
- Fiber optic customers have a higher churn tendency
- Electronic check users are more likely to churn
- Customers with shorter tenure are at greater risk of leaving

## Conclusion

This Power BI dashboard provides a comprehensive view of customer churn behavior and retention trends. By leveraging interactive visualizations and KPI metrics, businesses can identify high-risk customer segments and make informed decisions to improve customer retention and reduce revenue loss.
